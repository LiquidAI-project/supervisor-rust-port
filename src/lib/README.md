## Description

This library contains following files originally from [Wain](https://github.com/rhysd/wain) WebAssembly interpreter:

- cast.rs
- globals.rs
- import.rs
- leb128.rs
- memory.rs
- parser.rs
- runtime.rs
- source.rs
- stack.rs
- table.rs
- trap.rs
- value.rs
- wain_ast.rs
- wain_syntax_binary.rs
